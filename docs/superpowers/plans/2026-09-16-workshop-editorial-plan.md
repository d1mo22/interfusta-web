## Global Constraints

- Next.js 14 App Router, Tailwind v3, shadcn/ui. No new npm dependencies. Icons: `lucide-react` only (already installed).
- Public pages only: `app/page.tsx`, `app/about/page.tsx`, `app/services/page.tsx`, `app/contact/page.tsx`, `app/portfolio/**`, `components/navigation.tsx`, `components/footer.tsx`. Do not edit `app/admin/**`, `app/auth/**`, or any file in `components/ui/`. Admin must render as before except body font.
- Same URLs, same nav labels ("Serveis", "Projectes", "Sobre Nosaltres", "Contacte"), same form field names, same data sources.
- Copy: keep the existing Catalan strings, but headings and button labels switch to sentence case exactly as in the mockups (e.g. "Els nostres serveis", "Veure el nostre treball", "Enviar missatge", "Veure detalls", "Llest per començar el teu projecte?"). The home CTA band button label is "Contacte".
- Tokens (hex CSS variables, see Task 1). Light: paper `#F6F5F2`, stone `#ECEAE5`, ink `#171614`, ink-muted `#6B6862`, hairline `#D6D3CC`, brand `#FC4108`, brand-ink `#C23100`. Dark (`.dark`): paper `#141312`, stone `#1C1B19`, ink `#F3F1EC`, ink-muted `#A29F98`, hairline `#2E2C29`, brand `#FC4108`, brand-ink `#FF8A5C`.
- Shape: `rounded-none` on every public element. No shadows, gradients, blur, glass, icon-badge cards, centered hero text, section numbers, middle-dot separators, em-dashes.
- Fonts: `font-display` (Bricolage Grotesque) for headings, `font-sans` (Geist) body, `font-mono` (Geist Mono) only for real data (phone, hours, years, numerals).
- Orange usage: `.rule` (96×4 brand bar) under page headlines; one `<span class="text-brand">` word per page headline as in mockups; active nav/filter underline `decoration-brand`; link hover `text-brand-ink`; CTA buttons `bg-brand`; the home CTA band is the only full orange surface.
- Mono label budget: at most one small mono uppercase label per page (the hero has it on home). Otherwise no eyebrows.
- Motion: CSS only. `transition-[color,background-color,transform]` etc., never `transition-all`. Hover transforms only inside `@media (hover:hover) and (pointer:fine)`. `prefers-reduced-motion: reduce` removes movement, keeps fades. Theme switch instant. No scroll-triggered animation.
- Hero uses `min-h-[100dvh]`, never `h-screen`.
- After every task: `npm run build` passes with zero lint errors (remove unused imports). Commit per task with a short message in English plus the trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
